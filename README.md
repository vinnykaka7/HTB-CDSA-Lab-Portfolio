#  SOC Analyst & Defensive Security Portfolio

### *Hands-On Incident Response | Threat Hunting | SIEM Triage | Log & PCAP Analysis*

#  OVERVIEW

Welcome to my defensive security repository. This portfolio serves as a living logbook of my technical capabilities in Security Operations Center (SOC) workflows, threat analysis, and incident triage. 

Instead of relying solely on theoretical study, this repository bridges the gap between structured learning and real-world application. For every concept mastered through the **Hack The Box (HTB) Certified Defensive Security Analyst (CDSA)** pathway, I construct **three distinct, real-world scenario investigations**—simulating enterprise network traffic, host-level artifacts, and SIEM event logs to practice end-to-end incident handling.

### Key Competencies Demonstrated

* **Log & Artifact Triage:** Deep analysis of Windows Event Logs (`.evtx`), Sysmon logs, Linux `/var/log` records, and web server logs.
* **Network Traffic Analysis:** Packet capture (PCAP) parsing using `Wireshark` and `tshark` to identify C2 beaconing, exfiltration, and lateral movement.
* **SIEM & Querying:** Crafting structured queries in **Splunk (SPL)** and **Elastic (KQL)** for threat detection and anomaly hunting.
* **Threat Mapping & Detection:** Mapping adversary Tactics, Techniques, and Procedures (TTPs) directly to the **MITRE ATT&CK® Framework** and authoring custom **Sigma** detection rules.
